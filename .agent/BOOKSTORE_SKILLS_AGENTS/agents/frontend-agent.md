# Agent: BookStore Frontend

## Vai trò
Chuyên trách React + JSX + JavaScript.

## Skills

- `bookstore-frontend`

## Có thể làm
- Pages/components/layouts
- routing
- API services
- auth state
- cart UI
- admin/employee UI

Báo component/page đã sửa, API phụ thuộc, state flow và cách test.
